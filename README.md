# MediTrack – Healthcare Management System (Front-End)

A modern, responsive, clinical-grade **Hospital & Healthcare Management System** built with **React, Tailwind CSS, Lucide Icons, and LocalStorage Persistence**.

---

## 🚀 Easy Deployment Guide / అప్లోడ్ చేసే విధానం

### 1. Netlify లో అప్లోడ్ చేయడం (Recommended - 1 Click)
1. **Option A (Drag & Drop)**:
   - Run `npm run build` (లేదా ప్రాజెక్ట్ లోని `dist` ఫోల్డర్ తీసుకోండి).
   - [app.netlify.com/drop](https://app.netlify.com/drop) కు వెళ్లి `dist` ఫోల్డర్ ను డ్రాగ్ చేయండి.
   - వెంటనే మీకు లైవ్ లింక్ (Live URL) వచ్చేస్తుంది!
2. **Option B (GitHub ద్వారా Netlify)**:
   - Build Command: `npm run build`
   - Publish Directory: `dist`

---

### 2. Vercel లో అప్లోడ్ చేయడం (Zero-Config)
1. మీ GitHub repo ను [vercel.com](https://vercel.com) లో ఇంపోర్ట్ చేయండి.
2. Framework Preset: **Vite**
3. **Deploy** పై క్లిక్ చేయండి. Vercel ఆటోమేటిక్ గా బిల్డ్ చేసి లింక్ ఇస్తుంది.

---

### 3. GitHub Pages లో అప్లోడ్ చేయడం
1. ఈ ప్రాజెక్ట్‌ను GitHub repository కి పుష్ చేయండి.
2. `dist` ఫోల్డర్ లోని కంటెంట్‌ను `gh-pages` బ్రాంచ్ కి పుష్ చేయండి లేదా GitHub Actions ఉపయోగించి డెప్లాయ్ చేయండి.

## 🏥 Modules Included / ఫీచర్లు

1. **Dashboard Overview**:
   - 5 KPI Cards: Total Patients, Active Doctors, Today's Visits, Available Beds, Collected Revenue.
   - Pure SVG Patient Inflow & Discharge Trend Chart.
   - Department Census Donut Chart.
   - Today's Appointments Queue with quick status updater.
   - Hospital Ward & Bed Occupancy Matrix.
   - Live clinical activity audit trail.

2. **Patient Management**:
   - Register New Patient modal with complete clinical & contact fields.
   - Patient Medical Chart with vital signs (BP, Pulse, Temp, SpO2).
   - Edit and Delete patient records.
   - Live search by Name, Patient Code, or Medical Condition.

3. **Doctors & Specialists**:
   - Specialists directory with degrees, experience, fees, and duty schedule.
   - Instant live availability switcher (`Available`, `In Surgery`, `Busy`, `On Leave`).
   - Add and Edit doctor profiles.

4. **Appointment Management**:
   - Book appointment modal with dynamic patient and doctor selection.
   - Status filters: Upcoming, Completed, Rescheduled, Cancelled.
   - Printable Outpatient Consultation Pass.

5. **Medical Records (EHR)**:
   - Patient encounter history with symptoms, diagnoses, and treatment notes.
   - Dynamic multi-item prescription manager (medicine, dosage, timing, duration).
   - Printable clinical summary report.

6. **Pharmacy & Medicines**:
   - Drug inventory table with unit pricing and stock units.
   - Critical Low-Stock Warning banner.
   - 1-Click Quick Restock modal (+/- units).
   - Expiration date tracking.

7. **Billing & Invoices**:
   - Financial summaries (Total Billed, Total Collected, Pending Balance).
   - Generate invoice modal with dynamic service lines and automatic 5% tax calculation.
   - Official Printable Hospital Tax Invoice with itemized charges.
   - 1-Click "Mark Paid" settlement.

8. **Staff Portal & Role Switching**:
   - 1-Click demo role switcher: Dr. Alexander Hayes (CMO), Sarah Jenkins (Admin), Emily Watson (Reception).
   - Reset sample data button anytime.
